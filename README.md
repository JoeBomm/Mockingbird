# MockingBird

A proof-of-concept .NET middleware that intercepts calls to OpenAPI-defined endpoints that have no
real implementation yet, and returns realistic fake data generated by an LLM (via
[OpenRouter](https://openrouter.ai)). Frontend teams can build against the full API surface before
the backend exists — swap out `MockingBird.Middleware`'s registration later and the real endpoints
take over with no client-side changes.

## How it works

1. Flag an operation in your app's OpenAPI document with the vendor extension `x-mockingbird: true`
   (on the operation, or on the whole path item).
2. `MockingBird.Middleware` reads your app's own Swashbuckle-generated OpenAPI document at request
   time and builds a lookup of flagged (method, route) pairs and their response schemas.
3. A request that matches a flagged operation is short-circuited: MockingBird builds a prompt from
   the operation's response schema and the request's route/query parameters, asks an LLM to fill in
   realistic values, validates the result against the schema (retrying once on failure), and returns
   it with the operation's real status code and content type. Everything else passes through
   untouched.
4. Generated responses are cached in-memory per (route, method, params) so a dev session sees
   consistent data instead of a new roll on every request — bypass with the
   `X-MockingBird-Refresh` header.

## Projects

- **`src/MockingBird.Middleware`** — the middleware itself. `app.UseMockingBird()` +
  `builder.Services.AddMockingBird(...)`. The LLM integration lives behind `IMockProvider`.
  `OpenRouterMockProvider` (the default) and `BedrockMockProvider` (Amazon Bedrock's Converse API)
  are both selectable via `MockingBirdOptions.Provider`, and a `DeterministicMockProvider` fallback
  is used automatically when OpenRouter is selected but no API key is configured (keeps everything
  below runnable offline).
- **`src/MockingBird.TestApi`** — a fixture Web API with two real endpoints (`/v1/people`) as a
  control group and three mock-only endpoints (`/v1/orders*`) that exist only in the OpenAPI spec.
  See [its README](src/MockingBird.TestApi/README.md) for curl examples showing the two side by side.
- **`tests/MockingBird.Middleware.Tests`** — route-matching, schema-conversion, validation, and
  full-pipeline tests (against a fake provider), plus an end-to-end test running the real TestApi.

## Getting started

Requires the .NET 10 SDK.

```bash
dotnet build
dotnet test
dotnet run --project src/MockingBird.TestApi
```

Then see [`src/MockingBird.TestApi/README.md`](src/MockingBird.TestApi/README.md) for example
requests.

## Using it in your own app

```csharp
builder.Services.AddSwaggerGen(/* ... */);   // Swashbuckle, as normal

builder.Services.AddMockingBird(options =>
{
    options.OpenRouterApiKey = builder.Configuration["MockingBird:OpenRouterApiKey"];
    options.Model = "anthropic/claude-3.5-haiku";
    options.CacheEnabled = true;
    options.DocumentName = "v1";   // matches the name passed to SwaggerDoc(name, ...)
});

var app = builder.Build();
app.UseSwagger();
app.UseRouting();
app.UseMockingBird();   // after routing, before endpoint execution
app.MapControllers();
```

Then mark any not-yet-implemented operation with `x-mockingbird: true` — either via a Swashbuckle
`IDocumentFilter`/`IOperationFilter`, or by hand-authoring that part of the spec — and MockingBird
takes it from there.

### Using Amazon Bedrock instead of OpenRouter

```csharp
builder.Services.AddMockingBird(options =>
{
    options.Provider = MockProviderKind.Bedrock;
    options.Bedrock.Region = "us-east-1";
    options.Bedrock.ModelId = "anthropic.claude-3-5-haiku-20241022-v1:0";
    // AccessKeyId/SecretAccessKey optional — omit them to use the AWS SDK's default credential
    // chain (env vars, shared credentials file, instance/task role, etc.) instead.
});
```

### Secrets

`MockingBird.TestApi` loads a git-ignored `.env` file on startup (see
[`src/MockingBird.TestApi/.env.example`](src/MockingBird.TestApi/.env.example)) so you never need
to put API keys or AWS credentials in `appsettings.json` or type them into a shell each session.

## Scope

This is an SDK/middleware-mode POC only — there's no gateway/YARP mode.
